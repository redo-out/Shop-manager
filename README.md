# Shop-manager

a front end of a shop manager , got the product from a local host using fetch and displayed them over my html 

---------------------------------------------------------------------------------

at first all the products are shown in our webpage , u can use search to find an exact program either by it's name or by it's

description and there's a search by max price where u can get all the products that are equal or less than the price u enter

there are also 3 buttons to get products by availibility, the category and the last one to reset the products.
